```
上电 → 初始化(约3s) → 上电起第5秒自动开跑（单次，不循环）：
  开风机阶梯升到1539 → 稳1s
  → GO_DOWN(-85)                下滑到最大下滑角85°
  → 刹车 → 稳200ms
  → 探头柔压 25°（499→778 线性 1s；协同仍瞬跳 1055≈50°）
  → 探头下压作业 20s            Coop_ServoHoldActive(20000)，见 §5
  → 1639 稳500ms
  → Coop_LiftThenGoUp：探头5s慢抬，抬满1s后开始回程（重叠）
```

## 4. 真实协同 AUTO 全流程（正式版）

```
等 COOP（母机 App 0x19 启动协同后经 NRF 下发）
1. 开风机：6步阶梯升速 → 固定1539，稳1s
2. REDY① → 等 GOON①（母机 PB9下压/夹持器开/记视觉参考后放行）
3. Compose_IMU：采100次姿态均值 → roll_Compose（回程基准）
4. GO_DOWN(-90)：IMU roll 闭环，近目标减速（<10°→-40，<5°→-15），30s超时（11-03 曾试-95后回退90）
5. 到底：motor_STOP + A轮4199刹车 → 稳200ms
6. 探头柔压 1s 至 25°(DUO 778) + Pi_SendCap()   ← 正式版照常发 CAP（树莓派采集）
7. Coop_ServoAHold(22000)              ← 探头下压作业 22s
   零速主动保持（§5）+ 风机加一档→1639（作业全程）
   每10ms：Coop_ReportIMU（200ms限频）、Ae_Poll、可中止
8. 1639 保持 500ms
9. Coop_LiftThenGoUp：探头5s慢抬，抬满1s后开始 GO_UP（与剩余抬升重叠）
   GO_UP(roll_Compose) 回到出发基准角；剩余<30°自动降吸两档；30s超时
10. REDY② → 视觉纠偏闭环 Adj_WaitLoop（§6）
11. 母机判收敛发 GOON② → DONE（等LOCK期间每800ms补发）
12. 等 LOCK → 关风机（阶梯降回939）→ ACKD → 回到等 COOP（循环）
```

任一步收到 STOP 或遥控非零帧（`Coop_TakeAbort`）→ 刹轮、保持吸力、回手动，不上报 DONE。

## 5. 作业保持的两种实现（A/B 对照实验记录）

### 背景：为什么"抱死"锁不住

轮电机为双通道 H 桥驱动（TIM4：A 轮 CH1/CH2，B 轮 CH3/CH4）。
"抱死"= 两通道同写 4199（两端同高，短接刹车）。**短接刹车的制动力来自反电动势，
而反电动势正比于转速——静止时 = 0，即零保持力矩**。探头下压的反力会把整车推得
缓慢滑动（实测确认，换软轮后依旧）。

### 两种实现（都在固件里，测试模式可一键切换）

| 函数 | 机制 | 实测（2026-11-02/03，同条件：软轮/20s/-85°/1639） |
|---|---|---|
| `Coop_ServoHoldBrake(ms)` | 纯抱死：每10ms写 4199/4199 + MB_STOP | **仍微滑** |
| `Coop_ServoHoldActive(ms)` | **零速闭环主动保持**：目标0速，微滚立即反向通电（kp=18/ki=90/dt=10ms，双向出力，积分限幅±4000），静止断电 | **明显改善** |
| `Coop_ServoAHold(ms)` | 协同 AUTO 用，**委托 HoldActive** | 同上 |

### 结论

静止短接电机没有保持力矩（物理决定，PWM 怎么写都一样）；
**"静止锁死"的正解是主动通电堵转出力**——零速闭环把 GO_UP 爬升时那套
"力够大"的闭环搬到静止状态用。软轮子（2026-11-02 更换）为叠加改善因素。

> 注意：零速保持对抗的是**周向/姿态向**滑动；沿管轴的平移滑动 IMU 测不到，
> 自跑测试模式不纠，真实协同由回程后的视觉纠偏兜底（ax 轴向闭环）。

## 6. 视觉纠偏闭环（真实协同）

回程结束发 REDY② 后进入 `Adj_WaitLoop()`（空闲超时 60s，每 800ms 补发 REDY）：

- 收 `ADJ,<phi>,<psi>,<ax>` → `Adj_Execute()` → 完成回 REDY（可复测）
- 收 `GOON` → 对齐确认，退出 → 发 DONE
- 收 STOP/遥控 → 中止回手动

`Adj_Execute` 融合规划（死区 φ/ψ 0.5°、ax 2mm，死区内不动）：

```
φ → 周向弧长 dφ = φ · π/180 · R(250mm)
ax≠0：β = ±20°斜行航向
      ①自旋 (β − ψ) → ②斜行 L=|ax|/sinβ → ③摆正 (0−β) → ④周向 (dφ − L·cosβ)
ax=0：自旋 (0 − ψ) → 周向 dφ
```

- 每段：轮速 PID 慢速（ADJ_SPEED_REV=80 电机轴转/s）+ 编码器里程计到量即停
- 里程计：`ADJ_MM_PER_MOTORREV=0.3555`（π×43÷减速比380）
- 轮距：`ADJ_TRACK_MM=163`（2026-11-02 实测更新，原 145；影响自旋弧长换算）
- 段间 Settle 稳定；每 10ms 轮询中止；段边界发 'L' 日志帧、周期发 'J' 遥测帧

## 7. 树莓派串口网关（USART1，`PI_LINK_EN=1`）

协议（ASCII，\n 结尾）：

```
子机 → Pi：CAP\n
Pi → 子机：OK CAP / R,cm=<f|空>,near=<n|空>,pd=<0|1|空>,st=<短码>
```

- st 短码（与母机/App 对齐）：`ok` `few` `bad` `err` `busy` `nopd` `near`(近场无数值) `out`(超显示范围)
- **全非阻塞设计**：`Pi_SendCap()` 是一次带 20ms 超时的 UART 发送（无接收方也照发）；
  `Ae_Poll()` 只看接收标志，无 Pi 时全部空转
- **没有树莓派时 AUTO 照常完整跑完**，只是无 AE 预测结果
- R 结果经 NRF 'D' 帧（flags + cm×10 + near + st）回母机转 App，200ms 限速补发
- 手动态另有 Pi 手动指令：W/X 进出作业模式、F±/F0 风机、S± 舵机、F=/S= 直设 PWM

Pi 侧代码（另一工作区路径）：`树莓派模型/E盘优化版_预测集成/`——
`ae_uart_service.py`（systemd 常驻）+ `main.py`（SpotWave 采集）+ `predictor_10_20/cap_prediction.js`（CAP 最终预测）。

## 8. NRF 协议帧速查

4 字节 ASCII 帧，接收侧在 32 字节载荷里做滑动子串匹配，无长度/校验字段。

| 方向 | 帧 | 含义 |
|---|---|---|
| 母→子 | COOP | AUTO 周期开始 |
| 母→子 | GOON | ①放行下行作业 ②纠偏对齐确认（退出 Adj_WaitLoop） |
| 母→子 | LOCK | 锁定确认，子机关风机回 ACKD |
| 母→子 | STOP | 中止（清摇杆，回手动） |
| 母→子 | ADJ,φ,ψ,ax | 纠偏量 |
| 母→子 | TSTA / TSTE | 进入/退出独立纠偏测试（与 COOP 二选一） |
| 子→母 | REDY | ①风机就绪 ②GO_UP 结束待纠偏 ③纠偏单步完成（800ms 补发） |
| 子→母 | DONE | 本周期完成（等 LOCK 期间 800ms 补发） |
| 子→母 | ACKD | 收到 LOCK，风机已关 |
| 子→母 | 'I'+pitch+roll | 协同期间每 200ms 姿态 |
| 子→母 | 'J'+11B | 纠偏段遥测 |
| 子→母 | 'L'+文本 | 纠偏段日志 |
| 子→母 | 'D'+flags+数据 | AE 预测结果（cm×10/near/st，200ms 限速补发） |

## 11. 与母机/App 的分工边界

- 子机只做**运动执行与协同握手**；视觉偏差由母机（ESP32-S3，拉 K230 `/align/*`）
  计算后经 NRF 以 ADJ 帧下发——子机不碰图像
- AE 预测数值由树莓派计算，子机只做 UART↔NRF 网关转发
- App 侧显示：协同阶段/告警（0x88）、AE 预测 cm/标准点
